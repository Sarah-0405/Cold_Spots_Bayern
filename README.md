# Cold Spots Bayern
Notebook enthält Code zur Berechnung von LST-Cold Spots aller bayerischen Städte mit >50.000 Einwohner*innen 
zunächst werden die Stadtpolygone mit OSMnx erstellt, und für alle Städte die Landsat 8 Daten der Sommermonate der Jahre 2019 bis 2024 bezogen. 
Darauf basierend werden die mittleren Sommer-LSTs berechnet und Cold Spots klassifiziert.
